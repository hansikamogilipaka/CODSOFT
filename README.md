# CODSOFT
RuleBot 🤖 – A Professional Rule‑Based Chatbot Website
📌 Overview
RuleBot is a lightweight, interactive chatbot built entirely with HTML, CSS, and JavaScript.
It simulates conversational responses using simple rule‑based logic, designed as a professional website interface.

This project demonstrates how to combine frontend design with chat logic to create a responsive, user‑friendly chatbot without requiring a backend server.

✨ Features
🌙 Dark Mode Toggle – Switch between light and dark themes seamlessly.

💾 Chat History Persistence – Messages are saved in localStorage so conversations remain after page refresh.

⌛ Animated Typing Effect – Bot replies appear character‑by‑character for a realistic typing feel.

🧠 Rule‑Based Responses – Handles greetings, time queries, jokes, quotes, facts, study tips, and more.

🎨 Modern UI Design – Clean card layout, responsive styling, hover effects, and smooth transitions.

⌨️ Keyboard Support – Press Enter to send messages quickly.
